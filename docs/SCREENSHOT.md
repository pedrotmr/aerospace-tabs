# Screenshot capture

`Screenshots/aerospace-tabs-workspaces-placeholder.svg` is the only image currently in `Screenshots/`. It is a clearly labeled placeholder, not a product capture. The older synthetic strip and disconnected-state PNGs have been removed.

## Suggested frame

- Capture the real app's tab strip with at least two occupied AeroSpace workspaces on one display. Keep workspace numbers, app icons, and window titles visible.
- Put two ordinary app windows in each workspace so the grouping is easy to see. Use harmless sample content and close notifications; do not expose personal window titles, messages, or file paths.
- Capture the full display at native resolution as PNG. Keep the strip and enough desktop around it to show where it sits; avoid retouching the app UI.
- An optional second image can show Window Overview open, with thumbnails from multiple workspaces visible.

Replace the placeholder with the real capture only after checking it contains no private desktop content. The current app is not running with AeroSpace in this environment, so no real capture was possible here.
